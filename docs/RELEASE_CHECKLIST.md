# V2 发布检查清单

## 一、首次 Beta 前

- [ ] `v0.1.0` 标签已推送到 GitHub，V1 安装包已另行保存，可随时回滚。
- [ ] 仓库只保留 `validate.yml`、`publish-mobile.yml`、`build-windows.yml`、`release.yml` 四个有效工作流。
- [ ] `package.json`、Service Worker、Tauri 与 Cargo 均为 `0.2.0-beta.1`。
- [ ] 已手动运行一次“构建 Windows”；如产生 `generated-cargo-lock` Artifact，已把其中的文件放回 `src-tauri/Cargo.lock` 并提交。
- [ ] `src-tauri/Cargo.lock` 已提交，关键依赖没有无意漂移；否则 Release 会主动停止。
- [ ] Git 状态干净，V1 原型参考文件仍在，角色视觉没有重绘。
- [ ] `验证 V2` 工作流的 Web 与 Rust 两项均为绿色对勾。

## 二、发布 `0.2.0-beta.1`

- [ ] 创建并推送精确标签 `v0.2.0-beta.1`。
- [ ] `发布手机版 PWA` 成功，V1 根路径仍可打开。
- [ ] `https://869909823.github.io/liangliangqiangqiang/beta/` 打开的是 V2。
- [ ] `/beta/` 的安装、离线启动和刷新提示正常，且没有读到根路径的 V1 缓存。
- [ ] `发布 GitHub Release` 成功，Release 标记为 Pre-release。
- [ ] Release 同时包含 NSIS `.exe` 与 `SHA256SUMS.txt`，本地校验值一致。

## 三、Windows Beta 验收

- [ ] Edge、Word 等应用成为前台后 500ms 内隐藏；Win+D 后 500ms 内恢复且不抢焦点。
- [ ] 普通模式可被其他窗口覆盖；置顶模式保持最前。
- [ ] 10%、80%、100%、130%、200% 无裁切（受显示器工作区动态限制），气泡和点击区域同步缩放。
- [ ] 100%、150%、200% DPI 和左右负坐标双屏正常。
- [ ] 拔掉副屏、修改分辨率、Explorer 重启和睡眠唤醒后仍在可见区域。
- [ ] 设置重启后恢复；重复启动只有一个宠物和托盘。
- [ ] 鼠标穿透可从托盘关闭；重置位置可把宠物救回主屏右下角。
- [ ] V2 覆盖安装 V1 成功，不出现终端窗口，退出 2 秒后无残留进程。

## 四、状态、动作与声音验收

- [ ] V1 六种状态的脸型、花纹、围巾、鱼吊坠、键盘和比例没有退化。
- [ ] `moyu` 三次敲击的画面与声音误差不超过约 100ms，快速重复不会叠音。
- [ ] 默认静音；隐藏、睡眠、减少动画和手机后台时完全无声。
- [ ] 伸懒腰、打哈欠、吃小鱼干、偷看用户只在待机出现。
- [ ] 手动状态会取消一次性动作、声音和旧计时器。
- [ ] 自动陪伴不伪造工作、错误或完成，摸鱼满足待机时长和冷却限制。

## 五、手机 Beta 验收

- [ ] Android Chrome 与 iPhone Safari 均可添加到主屏幕。
- [ ] 首次联网完整打开后，断网仍能启动并加载角色及本地声音。
- [ ] 第一次用户点击前不播放声音；进入后台立即停声并暂停调度。
- [ ] 横屏、竖屏、刘海安全区及不同缩放下无裁切。
- [ ] 新版本出现“点击刷新”，刷新后版本更新且设置没有丢失。

## 六、发布稳定版 `0.2.0`

- [ ] 所有 Beta 阻断问题已关闭，双屏、DPI 与升级测试有记录。
- [ ] 四处版本号从 `0.2.0-beta.1` 同步改为 `0.2.0`，Service Worker 缓存版本随之变化。
- [ ] `npm run validate` 与云端 `验证 V2` 均通过。
- [ ] 创建并推送标签 `v0.2.0`。
- [ ] 手机版根路径已替换为 V2，Release 不是 Pre-release 且被标记为 Latest。
- [ ] 从 Release 新下载的安装包可覆盖 V1 和 Beta，SHA-256 校验一致。
- [ ] V1 安装包与 `v0.1.0` 标签仍保留，不删除回滚入口。

出现阻断问题时停止稳定发布：Windows 回滚到保留的 V1 安装包，手机版重新手动运行 `发布手机版 PWA` 并选择 `beta`，即可让根路径恢复 `v0.1.0`。
